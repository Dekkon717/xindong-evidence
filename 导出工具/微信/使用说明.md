# 微信聊天记录导出说明（Windows）

## 先说明边界

微信聊天数据库是加密存储的，`心动证据局`不会直接读取或解密微信数据库。请使用你指定的 [wechat-chat-export](https://github.com/zhuzhangxue/wechat-chat-export) Windows 工具，先得到可读的 JSON、TXT 或 Markdown 文件。

本目录已附官方 v1.3.0 单文件程序：

`WeChat-Chat-Export-for-LLM.exe`

## 操作流程

1. 登录 Windows 微信，并保持微信在后台运行。
2. 双击本目录中的 `WeChat-Chat-Export-for-LLM.exe`。
3. 输入好友的准确备注、昵称或群名；按需要勾选图片、文件、语音、视频和本地语音转文字。
4. 如果自动探测的数据目录不正确，在工具中手动选择微信数据目录。
5. 点击“开始导出”，优先使用导出的 `chat_full_parsed.json`；TXT / Markdown 也可以直接导入本页面。
6. 如果页面没有自动判断“你 / TA”，在导入区填写本人昵称 / ID；若双方昵称已识别但无法确认本人，再从候选按钮中选择“哪个是我”。

## 进入分析页面

回到上一级目录，双击 `index.html`；如果浏览器限制本地页面，也可以在项目根目录运行：

```powershell
py -m http.server 8000
```

然后打开 `http://localhost:8000`，把 JSON 拖入页面，点击“开始观测”。

## 导入前检查

- 不要把 `analysis_prompt.txt`、终端日志或调试输出当成聊天记录导入；
- 导出文件至少要能看见时间、发送者和消息内容；
- 微信名片、公众号、小程序等结构化消息可能不是普通文本，页面会把它们标成结构化消息，不会把头像 URL、地区、alias 等内部属性当作原话；
- 如果记录里没有明确发送方向，分析会要求你确认本人身份，不会把发送方向硬猜出来。

## 隐私与安全

不要把微信数据库文件、登录凭据或原始聊天记录发给陌生人。工具的下载地址、版本和运行要求以 [wechat-chat-export 官方仓库](https://github.com/zhuzhangxue/wechat-chat-export) 和 [v1.3.0 Release](https://github.com/zhuzhangxue/wechat-chat-export/releases/tag/v1.3.0) 当前说明为准。该项目使用 Apache-2.0；官方说明称 Windows EXE 未配置商业代码签名，首次运行可能出现 SmartScreen 提示，不要因此关闭 Defender 或添加安全排除项。
