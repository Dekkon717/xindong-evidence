# QQ 聊天记录导出说明（Windows）

## 下载工具

本目录已附 QQ Chat Exporter 官方 Windows x64 一键安装包：

`QQChatExporter-Installer-v6.2.8.exe`

如果需要更新版本，再从 [QQ Chat Exporter 官方 Releases](https://github.com/shuakami/qq-chat-exporter/releases/latest) 下载页面标记的 Installer；不要从网盘、评论区或不明镜像下载 exe。

QQ Chat Exporter 是独立运行的导出工具。本项目不再连接它的本机 API，也不会要求你填写 `127.0.0.1` 地址、端口或访问令牌。

## 操作流程

1. 安装并启动 QQ Chat Exporter；如果工具要求 QQ 已登录，请先完成 QQ 登录。
2. 按工具页面选择好友或群聊，并执行导出。
3. 导出格式优先选择 JSON；如果只有 TXT / MD，也可以导入，但需要文件中保留时间和发送者标识。
4. 将导出文件放入本文件夹，或直接拖入上一级页面的文件上传框。
5. 点击“开始观测”。页面会从导出文件中识别发送方向，并只基于这一次导入的数据重新计算报告。

## 导入失败时检查

- 确认导入的是导出结果，不是 QQ Chat Exporter 的启动日志或配置文件；
- JSON 顶层可以是消息数组，也可以是包含 `messages` 数组的对象；
- 如果导出结果带有 `isSend`、`direction`、`senderUid`、`senderUin` 或昵称字段，页面会优先使用这些字段判断“你 / TA”；
- 如果双方昵称已识别但本人方向仍不明确，请在导入区填写本人昵称 / ID，或点击候选昵称；
- 页面看到的 `[图片]`、`[语音]`、`[结构化消息]` 是导出数据中的非文本消息占位，不代表读取报错。
