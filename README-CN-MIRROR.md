# 心动证据局｜中国大陆镜像发布包

这个发布包是一个完全静态的网站版本，适合上传到中国大陆的云主机、对象存储静态网站或 CDN。

## 包含内容

- `index.html`
- `styles.css`
- `app.js`

网页不依赖外部字体、CDN、后端接口或海外 API。聊天文件只在访问者自己的浏览器内读取和计算，不会因为部署镜像而上传到服务器。

## 发布方式

将这三个文件放在网站根目录，并把 `index.html` 设置为默认首页即可。国内常见方案包括：

1. 国内云主机 + Nginx；
2. 国内对象存储静态网站；
3. 国内 CDN + 国内对象存储源站。

如果使用自定义域名，需按所选云厂商的要求完成域名实名认证、ICP备案及 HTTPS 配置。临时测试也可以先使用云厂商提供的测试域名或 IP 地址。

## 上线前检查

- 浏览器直接打开首页后能看到示例分析；
- 选择 JSON/TXT 文件后能完成本地分析；
- 断开外网后，已经打开的页面仍能继续分析本地文件；
- HTTPS 正常后，再给用户分享正式域名。

本包不包含聊天记录、统计结果或其他个人数据。
